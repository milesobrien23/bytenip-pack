# Rest of the pack

ByteNip 1.3.1 has 129 mods; the [Mekanism guide](mekanism.md) covers the 4 Mekanism jars and these tables cover the rest, grouped by what you use them for. Step-by-step starts for the major mods are in [Beginner guides](beginner-guides.md). Names come from each mod's Modrinth page.

## Tech and automation

Create and AE2 are the two big systems next to Mekanism; Create Crafts & Additions and Applied Mekanistics tie all three together.

| Mod | What it does | Start here |
| --- | --- | --- |
| Create | Rotation-powered machines: presses, mixers, belts, contraptions, trains. | Hover a Create item in your inventory or JEI and hold W for its animated Ponder tutorial. |
| Create Crafts & Additions | Converts Create rotation ↔ FE, adds wires and rolling mill parts. | Alternator on a Create shaft to power Mekanism. |
| Steam 'n' Rails | More track types, signals and train parts for Create trains. | Needs a working Create train line first. |
| Create: Enchantment Industry | Automates enchanting and XP as a fluid. | Blaze Enchanter and Printer. |
| Create Slice & Dice | A Create slicer that automates Farmer's Delight cutting-board recipes. | Put it over a depot or belt. |
| Create: Bells & Whistles | Decorative and utility parts for Create trains and contraptions. | Browse in JEI. |
| Create: Dragons Plus | Small Create utilities and a library for other Create add-ons. | Mostly runs in the background. |
| Create: Applied Kinetics | Makes AE2 processors and inscriber presses through Create sequenced assembly; adds an Energy Provider and ME Proxy. | Look up AE2 processors in JEI. |
| Applied Energistics 2 | Digital storage network with autocrafting. | AE2's in-game guide, then meteorites for presses. |
| AE2 Wireless Terminals | Wireless crafting, pattern and universal terminals. | Needs a Wireless Access Point. |
| MEGA Cells | Storage cells from 1M to 256M, bulk cells, chemical and radioactive cells. | Late AE2; needs Sky Steel. |
| Applied Flux | Stores and moves FE through ME. | Flux Accessor on a machine. |
| Applied Mekanistics | Chemicals on ME (see the Mekanism guide). | Chemical cell housing. |
| Ars Énergistique | Stores Ars Nouveau source in ME: 1k–256k source cells, an ME Source Jar, and Source and Spell P2P tunnels. | Needs both mods running. |
| Integrated Dynamics | Logic-cable networks that read and react to almost any block. | Craft the "On the Dynamics of Integration" manual. |
| Integrated Terminals | Storage and crafting terminals for Integrated Dynamics networks. | Add after ID storage is set up. |
| Integrated Tunnels | Moves items, fluids and energy over ID cables, with filters. | Importer and exporter aspects. |
| CC: Tweaked | Lua-programmable computers, turtles and monitors. | Craft a Computer and run `help`. |
| Advanced Peripherals | Extra CC peripherals: ME and RS bridges, player and environment detectors, chat box. | ME Bridge for an AE2 dashboard. |
| Cyclic | A grab-bag of utility blocks, tools, enchantments and potions. | Browse in JEI. |
| Mystical Agriculture | Seeds that grow essence for 150+ materials, including Mekanism metals. | Mine Inferium ore and craft Prosperity seed bases. |
| Cable Facades + bytenip\_facades | Hide pipes and cables behind AE2 facades (ByteNip's own patch mod). | Right-click a pipe with an AE2 facade. |

## Magic

Six magic systems, each with its own guide book; Iron's Spells has the most add-ons in the pack.

| Mod | What it does | Start here |
| --- | --- | --- |
| Ars Nouveau | Build your own spells from glyphs; automate with rituals and familiars. | Craft the Worn Notebook from a book and lapis. |
| Ars Creo | Adds the Starbuncle Wheel, which turns a starbuncle's running into Create rotation. | After Ars basics. |
| Iron's Spells 'n Spellbooks | RPG spellcasting with schools, spellbooks, scrolls and mage armor. | Loot scrolls, then an Inscription Table to add them to a spellbook. |
| Cataclysm: Spellbooks | Iron's Spells gear and spells themed on L\_Ender's Cataclysm bosses. | Boss drops. |
| Apprentice's Codex | Early-game apprentice spells and items for Iron's Spells. | Browse in JEI. |
| Discerning the Eldritch | Expands Iron's Spells' Eldritch school. | Late Iron's Spells. |
| Alshanex's Familiars | Iron's Spells familiars: creatures you find and tame to fight beside you. | Explore; they spawn in the world. |
| Occultism | Summon spirits for storage, mining, crafting and transport. | Craft the Dictionary of Spirits. |
| Theurgy | Alchemy that breaks items into sulfur, salt and mercury to replicate and transmute them, metals included. | Read The Hermetica, its guide book. |
| Malum | Dark magic from soul spirits collected with scythes. | Craft a crude scythe and the Encyclopedia Arcana. |
| Goety | Necromancy and dark rituals powered by souls. | Read its in-game guide. |
| Goety Cataclysm | Ties Goety into L\_Ender's Cataclysm bosses and loot. | Needs both mods. |

## Adventure, world and server

Apotheosis and L\_Ender's Cataclysm set the combat difficulty; the worldgen mods mean new terrain and structures only appear in chunks generated after they were added.

| Mod | What it does | Start here |
| --- | --- | --- |
| Apotheosis | Affixed loot with rarities, gems and sockets, and harder mobs and bosses. | Socket gems at a Smithing Table; salvage gear at the Salvaging Table. |
| Apothic Enchanting | Reworked enchanting: shelves set Eterna, Quanta and Arcana, and level caps go higher. | Better bookshelves raise what the table can roll. |
| Apothic Spawners | Upgrade and move mob spawners with modifier items. | Silk Touch a spawner. |
| Apothic Attributes | The attributes screen and the extra stats Apotheosis gear uses. | Open it from the inventory. |
| L\_Ender's Cataclysm | Big dungeons and boss fights with strong gear drops. | Use a map or JEI to find the boss structures. |
| YUNG's Better Dungeons / Mineshafts | Redesigned vanilla dungeons and mineshafts. | Explore. |
| Dungeons and Taverns | Extra dungeons, taverns and other structures. | Explore. |
| Towns and Towers | New villages, outposts and ships. | Explore. |
| Terralith | About 100 new biomes from vanilla blocks. | Explore. |
| Tectonic | Taller, more varied terrain shaping. | Explore. |
| Waystones | Teleport between activated waystones, plus warp scrolls and stones. | Right-click any waystone you find to activate it. |
| GraveStone | Stores your inventory in a grave where you die. | Right-click the grave to get your items back. |
| SecurityCraft | Keycards, cameras, mines, laser fences and owner-locked blocks. | Craft the SecurityCraft Manual. |
| Open Parties and Claims | Claim chunks and form parties; claims show on Xaero's maps. | Claim from the world map or with `/openpac`. |

## Interface and performance

JEI and Jade answer most "what is this and how do I make it" questions; the performance mods need no setup.

| Mod | What it does | Use |
| --- | --- | --- |
| JEI | Recipe and item browser. | R on an item for recipes, U for uses. |
| Jade | Tooltip for the block you look at: contents, energy, progress. | Look at a block. |
| Xaero's Minimap / World Map | Minimap, full map and waypoints; shows claims from Open Parties and Claims. | M for the world map. |
| AppleSkin | Shows hunger, saturation and what food restores. | Automatic. |
| Mouse Tweaks | Drag and scroll to move item stacks. | Automatic. |
| Controlling | Search bar and conflict check in Key Binds. | Options → Controls → Key Binds. |
| Controlify | Full controller support. | Plug in a controller. |
| Controlify JEI Keyboard Fix (ByteNip) | Controller typing into JEI search, Iron's Spells wheel on the right stick, right-stick scrolling in AE2 terminals. | Automatic with a controller. |
| LambDynamicLights | Torches and glowing items light up the area while held. | Automatic. |
| Chunky | Pre-generates the world to cut lag while exploring. | Server admins: `/chunky start`. |
| Sodium, ImmediatelyFast, Entity Culling | Client rendering speedups. | Automatic. |
| Lithium, ModernFix, FerriteCore | Game-logic, load-time and memory improvements. | Automatic. |
| spark | Lag profiler. | `/spark profiler start` when the server stutters, then `/spark profiler stop` for a report link. |

## Libraries

These 33 mods add nothing you use directly; other mods need them, so never remove one on its own: Ace's Spell Utils, Athena, AzureLib, Balm, Cloth Config API, Common Capabilities, Cristel Lib, Cucumber Library, Curios API, Cyclops Core, Familiarslib, FLIB, GeckoLib, Glodium, GuideME, Iron's Lib, Kotlin for Forge, Lionfish-API, Lithostitched, Lodestone, MezzConfig, MezzConfigGUI, Modonomicon, Moonlight Lib, Patchouli, Placebo, playerAnimator, Resourceful Lib, Searchables, SmartBrainLib, Sophisticated Core, YetAnotherConfigLib and YUNG's API.

Curios adds the extra accessory slots that rings, charms and some magic gear use.
