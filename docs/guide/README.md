# ByteNip player guide

A guide to the mods in the ByteNip pack (version 1.3.1), with Mekanism covered in the most depth.

| Page | What is in it |
| --- | --- |
| [Mekanism](mekanism.md) | Concepts, progress map, every machine, ore yields, five starter builds, and how Mekanism ties into the rest of the pack. |
| [Beginner guides](beginner-guides.md) | First steps for 20 other mods, each with a "Works with" line. |
| [How mods interact](how-mods-interact.md) | A diagram and tables of every link between mods, plus what does not connect. |
| [Rest of the pack](rest-of-the-pack.md) | One line on each of the 129 mods, grouped by purpose. |

The [interactive version](https://claude.ai/artifact/26XUq43RtDHHiJrmx6uZi4) has tickable steps and a progress tracker. These pages are a snapshot of it from Nov 11, 2026.

Recipes and item names were checked against the mod files in the pack. Step order comes from general knowledge of each mod, so confirm details in JEI.
